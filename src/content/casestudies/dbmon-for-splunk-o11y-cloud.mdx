Database monitoring is a critical aspect of maintaining the health and performance of databases. This case study explores how we implemented database monitoring for Splunk Observability Cloud, a leading platform for observability and monitoring.

## Opportunity

A database has multiple moving parts. It has the host on which a database server runs. This database server manages multiple databases, each having its own set of tables, indexes, and other objects. Queries are executed against these databases to retrieve or manipulate data. Each of these components can impact the overall performance and reliability of the database system.

Splunk Observability Cloud was already capable of monitoring such hosts but lacked the ability to monitor the database server and its components in detail. This presented an opportunity to enhance the monitoring capabilities of Splunk Observability Cloud by adding database monitoring features.
