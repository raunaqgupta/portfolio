I built out [somewhatmagicaljevball.com](somewhatmagicaljevball.com) to explore using Jev for sentimental analysis. The magic 8 ball symbolism has an undertone of a personality which felt like an interesting example to simulate using an AI model.

![](https://photos.raunaqgupta.com/blog/2026-11-03-launching-somewhat-magical-jev-ball/screen.png)

Here's a video reel of the various micro-interactions. The floating blurbs are prompts being entered by live users on the site. They are also supplemented with prompts from a pre-generated list.



"... [Fun is] the degrees to which the game recognizes and responded to the players' choices and actions." - Gabe Newell from https://www.youtube.com/watch?v=MGpFEv1-mAo was a great nudge to turn a sparse page with a dark spherical object more "fun".

Also some great posts on dithering were used to understand how to incorporate such an effect on the 3d render: https://tympanus.net/codrops/2025/06/04/building-a-real-time-dithering-shader/, and https://blog.maximeheckel.com/posts/the-art-of-dithering-and-retro-shading-web/.

Design artifacts were made in https://paper.design/. Paper's mcp server works great to handoff artifacts. All code was written by Claude Sonnet 5, and is hosted at [https://github.com/raunaqgupta/somewhat-magical-jev-ball]()

The video reel was made using Cleanshot's new studio mode.
