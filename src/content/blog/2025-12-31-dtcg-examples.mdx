DTCG (Design Tokens Community Group) defines a standard for design tokens using the JSON format. The [specification](https://www.designtokens.org/tr/2025.10/) is divided into three modules: [Format](https://www.designtokens.org/tr/2025.10/format), [Color](https://www.designtokens.org/tr/2025.10/color/), and [Resolver](https://www.designtokens.org/tr/2025.10/resolver/).

## Color tokens

Color tokens has its own module within the specification as described [here](https://www.designtokens.org/tr/2025.10/color/). This example define three color tokens of the [base category](https://www.designtokens.org/tr/2025.10/color/#base). DTCG tokens are infinitely nestable to create appropriate hierarchies. Here, we have a `color` token that contains a `palette` token that contains a `gray` token that contains three color definitions.

```json
{
  "color": {
    "palette": {
      "gray": {
        "1000": {
          "$type": "color",
          "$value": {
            "colorSpace": "oklch",
            "components": [1, 0, 0],
            "alpha": 1,
            "hex": "#ffffff"
          }
        },
        "900": {
          "$type": "color",
          "$value": {
            "colorSpace": "oklch",
            "components": [0.9911, 0, 0],
            "alpha": 1,
            "hex": "#fcfcfc"
          }
        },
        "0": {
          "$type": "color",
          "$value": {
            "colorSpace": "oklch",
            "components": [0, 0, 0],
            "alpha": 1,
            "hex": "#000000"
          }
        }
      } 
    }
  }
}
```

Their equivalent CSS variables would end up as:

```css
:root {
  --color-palette-gray-1000: oklch(1 0 0);
  --color-palette-gray-900: oklch(0.9911 0 0);
  --color-palette-gray-0: oklch(0 0 0);
}
```
