Development work included migration from Gatsby to Next.js alongside Stitches.js as the styling framework.

![PlanetScale Docs inline zoom component](/sundries/planetscale_docs_inline_image_zoom.png)

In a 3-column layout, clicking on an image zooms it to take up space equal to last 2 columns. The image will overlay the in-page navigation but zooms out on scrolling out of view.
