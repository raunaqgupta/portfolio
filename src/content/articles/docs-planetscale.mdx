What better way to use a cloud database then to build an internal forum for the company itself? Flux was built as a dogfooding exercise to test PlanetScale's capabilities as a cloud database. It was built using Next.js and hosted on Vercel, with PlanetScale serving as the backend database.

I provided visual design, UX design, and front-end development aided by a backend engineer.
