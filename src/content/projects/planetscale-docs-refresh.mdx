PlanetScale documentation refresh in 2021. Illustrations by [Shaun Middlebusher](https://www.linkedin.com/in/shaun-middlebusher). Design work included maintaining parity with the ongoing visual refresh of [PlanetScale's web application](https://app.planetscale.com). Development work included migration from Gatsby to Next.js alongside Stitches.js as the styling framework.

![PlanetScale Docs inline zoom component](https://imagedelivery.net/s34zmbsS583k_zL8HLfX6w/9a582807-19ee-485d-13a6-65bdba5eb500/public)

In a 3-column layout, clicking on an image zooms it to take up space equal to last 2 columns. The image will overlay the in-page navigation but zooms out on scrolling out of view.
